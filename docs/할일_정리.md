## 파이프라인 구조
 
```
사용자 질문
  → Query Rewriting       (구어체 → 검색 최적화 쿼리)
  → Intent Classification (6개 의도 분류 → 검색 전략 분기)
  → HyDE                  (학사일정 / 수강규정 / 기타 의도에만 적용)
  → Neo4j 키워드 검색 + ChromaDB 벡터 검색 (하이브리드)
  → LLM 답변 생성
```
 
### Query Rewriting 예시
 
| 원본 질문 | 재작성 쿼리 |
|---|---|
| 확률과통계 시간 언제야 | 확률과 통계 강의 개설 시간 및 요일 정보 |
| 물치과 전화번호 알아? | 물리치료학과 연락처 정보 |
| 패논패 언제까지야 | P/NP(Pass/None Pass) 성적처리 수강신청 기간 |
 
### Intent Classification 기준
 
| 의도 | 예시 질문 | 검색 전략 |
|---|---|---|
| 강의_시간표 | 확률과통계 시간 언제야 | Neo4j 우선 + ChromaDB 보조 (3개) |
| 교수_정보 | 김중헌 연구실 어디야 | Neo4j 우선 + ChromaDB 보조 (3개) |
| 학과_연락처 | 물리치료학과 전화번호 | Neo4j 우선 + ChromaDB 보조 (3개) |
| 학사_일정 | 패논패 언제까지야 | ChromaDB만 (7개) |
| 수강_규정 | 재수강 되나요 | ChromaDB만 (7개) |
| 기타 | 엘리베이터 고장났어 | Neo4j + ChromaDB 동등 (5개) |
