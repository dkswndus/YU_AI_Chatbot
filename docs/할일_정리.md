## 1단계: Query Rewriting 예시

| 원본 질문 | 재작성된 쿼리 | 비고 |
|---|---|---|
| 확률과통계 시간 언제야 | 확률과 통계 강의 개설 시간 및 요일 정보 | 정상 |
| 물치과 전화번호 알아? | 물리치료학과 연락처 정보 | 정상 |
| 패논패 언제까지야 | P/NP(Pass/None Pass) 성적처리 수강신청 기간 | LLM이 Failure No Penalty로 오정규화 → Pass/None Pass로 수정 |

|---|---|---|

| 기타 | 엘리베이터 고장났어 | Neo4j + ChromaDB 동등(5개) |
